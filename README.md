MEI encoding of the *Radetzky-Marsch*, Op. 228 by Johann Strauss Vater (Johann Strauss senior), following the two-hand piano reduction by Tobias Haslinger, n.d. [1848] plate number T. H. 10,996, following the scan uploaded to IMSLP (Petrucci Music Library) by Piupianissimo, 2014. IMSLP #322630, https://imslp.org/wiki/Special:ImagefromIndex/322630 (accessed 16 November 2026).
